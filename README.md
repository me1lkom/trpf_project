# Название проекта
Сервис сравнения предложений поставщиков.

## Назначение
Приложение для автоматизации выбора более выгодного предложения от поставщиков.
Сервис позволяет вводить резличные предложения от поставщиков на один и тот же товар, с последующим сравнением по различным параметрам.

## Целевая аудитория
- Менеджеры по закупкам
- Владельцы малого бизнеса, сами заниющиеся закупками

## Предметная область
Сервис предназначен для анализа предложений на один и тот же товар с учётом цены, объёма заказа и минимальной партии, установленной поставщиком.

## Основные сущности
- Поставщик
- Товар
- Предложение
- Пользователь

## Основные функции
- Расчёт итоговой стоимости закупки
- Сравнение двух предложений по цене и вывод лучшего
- Проверка соответствия объёма заказа минимальной партии от поставщика

## План развития
На следующих этапах планируется:
- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
