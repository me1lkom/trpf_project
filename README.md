# Сервис сравнения предложений поставщиков.

## Назначение
Приложение для автоматизации выбора более выгодного предложения от поставщиков.
Сервис позволяет вводить различные предложения от поставщиков на один и тот же товар, с последующим сравнением по различным параметрам.

## Целевая аудитория
- Менеджеры по закупкам
- Владельцы малого бизнеса, сами занимающиеся закупками

## Предметная область
Сервис предназначен для анализа предложений на один и тот же товар с учётом цены, объёма заказа и минимальной партии, установленной поставщиком.

## Основные сущности
- Пользователь
- Товар
- Поставщик
- Предложение


## Основные функции
- Просмотр списка пользователей;
- Добавление пользователей;
- Поиск пользователей по имени;
- Поиск пользователя по ID;

- Просмотр списка товаров;
- Добавление товаров;
- Поиск товаров по названию;
- Поиск товара по ID;

- Просмотр списка поставщиков;
- Добавление поставщиков;
- Поиск поставщиков по названию;
- Поиск поставщика по ID;

- Просмотр списка предложений от поставщиков;
- Добавление предложений от поставщиков;
- Поиск предложений от поставщиков по ID товара;
- Поиск предложений от поставщиков по ID поставщика;
- Фильтр предложений по максимальной цене.
- Фильтр предложений по максимальному сроку доставки.
- Сортировка предложений по цене.
- Поиск лучшего предложения по цене.
- Проверка минимальной партии предложения.
- Расчёт стоимости заказа по предложению.

## Структура проекта
- main.py — точка запуска;
- users.py - функции работы с пользователями;
- products.py — функции работы с товарами;
- suppliers.py — функции работы с поставщиками;
- offers.py - функции работы с предложениями;
- storage.py — сохранение и загрузка данных;
- utils.py — вспомогательные функции безопасного ввода;
- data/— JSON-файл данных;
- tests/ — автоматизированные тесты.

## Требования
- Python 3.10+;
- pytest;
- flake8.
