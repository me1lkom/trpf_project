# Сервис сравнения предложений поставщиков.

## Назначение
Приложение для автоматизации выбора более выгодного предложения от поставщиков.
Сервис позволяет вводить резличные предложения от поставщиков на один и тот же товар, с последующим сравнением по различным параметрам.

## Целевая аудитория
- Менеджеры по закупкам
- Владельцы малого бизнеса, сами заниющиеся закупками

## Предметная область
Сервис предназначен для анализа предложений на один и тот же товар с учётом цены, объёма заказа и минимальной партии, установленной поставщиком.

## Основные сущности
- Товар (название, описание, старана произодства)
- Поставщик (название, ИНН, телефон, данные)
- Предложение (цена, мин партия, срок доставки)


## Основные функции
- Просмотр списка товаров;
- Добавление товара;
- Поиск товара по названию;
- Просмотр поставщиков товара;
- Добавление поставщика к товару;
- Фильтрация поставщиков по максимальной цене;
- Фильтрация поставщиков по максимальному сроку доставки;
- Сортировка поставщиков по цене;
- Поиск лучшего предложения по цене;
- Проверка минимальной партии;
- Расчёт итоговой стоимости заказа;
- Сохранение и загрузка данных в JSON.

## Структура проекта
- main.py — точка запуска;
- products.py — функции работы с товарами;
- suppliers.py — функции работы с поставщиками;
- storage.py — сохранение и загрузка данных;
- utils.py — вспомогательные функции безопасного ввода;
- data/products.json — JSON-файл данных;
- tests/ — автоматизированные тесты.

## Требования

- pytest;
- flake8.
